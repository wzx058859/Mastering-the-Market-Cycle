# 《周期》网页开发指南

> 本文档详细记录了基于霍华德·马克斯《周期》(Mastering the Market Cycle) 构建数据驱动周期分析网站的完整步骤。

---

## 一、项目概览

### 1.1 目标

构建一个多页面静态网站，帮助用户：
1. 理解周期的核心含义和三大规律
2. 了解三类九种市场周期的分类体系
3. 通过真实数据判断当前处于周期的什么位置
4. 根据周期位置选择对应的投资策略

### 1.2 最终文件结构

```
周期/
├── index.html          # 首页：周期概述 + 实时市场数据
├── cycles.html         # 周期图谱：三类九种周期详解
├── thermometer.html    # 周期温度计：数据评估 + 手动评估
├── strategy.html       # 投资策略：有识、有胆、有备
├── css/
│   └── style.css       # 全局样式（暗色/亮色主题）
├── js/
│   └── common.js       # 公共逻辑（导航、主题、图表、工具函数）
└── DOCUMENT/
    ├── 周期温度算法说明.md
    └── 网页开发指南.md
```

### 1.3 技术栈

| 技术 | 用途 | 版本 |
|------|------|------|
| HTML5 | 页面结构 | - |
| CSS3 (Custom Properties) | 样式 + 主题切换 | - |
| JavaScript (ES2020+) | 交互逻辑 | Vanilla |
| ECharts | 数据可视化图表 | 5.x (CDN) |
| Google Fonts | Noto Serif SC + Inter | CDN |

### 1.4 数据源

| API | 无需认证 | 提供数据 |
|-----|---------|---------|
| historyofmarket.com | 是 | S&P 500 PE、VIX、年度收益、回撤、AIAE、利率 |
| dollarliquidity.com | 是 | HY 利差、DLI 评分、实际利率、M2、美元指数 |

## 二、Step 1 — 建立项目基础

### 2.1 创建目录结构


### 2.2 设计系统：style.css

设计参考了 [historyofmarket.com](https://historyofmarket.com/) 的编辑式叙事风格（深色背景、金色强调、衬线标题）。

**CSS 变量体系**（`:root` 中定义）：

```css
:root {
  /* 背景色阶 */
  --bg-primary: #09090b;      /* 页面背景 */
  --bg-secondary: #111113;    /* 次级背景 */
  --bg-card: #18181b;         /* 卡片背景 */
  --bg-elevated: #232326;     /* 抬升背景 */

  /* 文字色阶 */
  --text-primary: #e4e4e7;    /* 主文字 */
  --text-secondary: #a1a1aa;  /* 次文字 */
  --text-muted: #71717a;      /* 弱化文字 */

  /* 功能色 */
  --accent: #d4a853;          /* 金色强调 */
  --green: #4ade80;           /* 正向/上涨 */
  --red: #f87171;             /* 负向/下跌 */
  --blue: #60a5fa;            /* 信息/冷色 */
  --orange: #fb923c;          /* 警告/暖色 */

  /* 字体 */
  --font-serif: 'Noto Serif SC', serif;   /* 标题 */
  --font-sans: 'Inter', sans-serif;       /* 正文 */
}
```

**核心 CSS 组件**：

| 类名 | 用途 |
|------|------|
| `.site-header` | Sticky 导航栏，毛玻璃背景 |
| `.page-wrapper` | 内容区域，max-width 960px 居中 |
| `.hero` | 页面顶部英雄区 |
| `.section` | 章节容器，底部分隔线 |
| `.card` / `.card-grid` | 信息卡片网格 |
| `.panel` / `.panel-header` / `.panel-body` | 数据面板（包裹图表） |
| `.metric` / `.metric-row` | 指标卡片 |
| `.checklist` / `.checklist-row` | 评估清单 |
| `.gauge-*` | 温度仪表盘 |
| `.tab-group` / `.tab-btn` | Tab 切换 |

| `.data-table` | 数据表格 |

### 2.3 亮色主题

通过 `[data-theme="light"]` 选择器覆盖所有 CSS 变量：

```css
[data-theme="light"] {
  --bg-primary: #fafafa;
  --bg-card: #ffffff;
  --text-primary: #18181b;
  --accent: #b8860b;        /* 深金色，在白底上可读 */
  /* ... 其余变量 */
}
```

### 2.4 公共 JavaScript：common.js

`common.js` 在每个页面底部通过 `<script src="js/common.js"></script>` 引入，提供：

| 功能 | 函数/变量 |
|------|----------|
| 导航渲染 | `renderNav()` — 动态生成导航栏 + 高亮当前页 |
| 页脚渲染 | `renderFooter()` — 动态生成页脚 |
| 主题切换 | `initTheme()`, `toggleTheme()`, `updateThemeIcon()` |
| 数据获取 | `fetchJSON(url)` — fetch + 错误处理 |
| 数字格式化 | `formatNum()`, `formatPct()`, `valClass()` |
| 图表初始化 | `initChart(containerId)` — ECharts 实例 |
| 图表配色 | `CHART_THEME`, `baseChartOption(title)` |
| 主题联动图表 | `updateChartTheme(theme)` — 切换主题时更新图表配色 |

**导航结构**：

```javascript
const NAV_ITEMS = [
  { href: 'index.html', label: '首页' },
  { href: 'cycles.html', label: '周期图谱' },
  { href: 'thermometer.html', label: '周期温度计' },
  { href: 'strategy.html', label: '投资策略' },
];
```

**主题切换原理**：
1. `initTheme()` 在 `<script>` 加载时立即执行（DOMContentLoaded 之前），读取 `localStorage` 并设置 `<html data-theme="dark|light">`
2. CSS 变量随 `data-theme` 属性自动切换
3. 按钮通过 `toggleTheme()` 切换，同时更新 `localStorage` 和 `CHART_THEME` 对象


### 3.2 钟摆动画

纯 CSS 实现，模拟马克斯"情绪钟摆"概念：

```css
@keyframes pendulum-swing {
  0%, 100% { transform: rotate(35deg); }
  50% { transform: rotate(-35deg); }
}
```

### 3.3 实时数据图表

**S&P 500 PE 图表**：
- API: `historyofmarket.com/api/sp500/forward-pe.json`
- 数据格式: `{ trailing: [{ date, value }, ...] }`
- 图表类型: 面积折线图 + 两条 markLine（均值 ≈20，偏高 >25）

**VIX 恐慌指数图表**：
- API: `historyofmarket.com/api/sp500/vix.json`
- 数据格式: `{ series: [{ date, value }, ...] }`
- 显示最近 5 年数据，使用 `visualMap` 按阈值变色（<20 蓝，20-30 橙，>30 红）

**年度收益指标**：
- API: `historyofmarket.com/api/sp500/annual-returns.json`
- 数据格式: `{ series: [{ date, value, year, ytd }, ...] }`
- 注意 `value` 已经是百分比形式（如 8.22 表示 8.22%）

## 五、Step 4 — 周期温度计 (thermometer.html)

这是整个网站最核心、最复杂的页面。

### 5.1 页面结构

```
Hero → "给市场量体温"
§ I  → 市场关键指标（4 个指标卡片 + 3 个 ECharts 图表）
§ II → 市场评估指南（Tab 切换：主观评估 / 数据评估）
§ III → 周期温度（仪表盘 + 指针 + 判断文字）
```

### 5.2 § I 市场关键指标

4 个实时指标卡片：
- S&P 500 PE → `m-pe`
- VIX → `m-vix`
- 年内最大回撤 → `m-dd`
- 最近年度收益 → `m-ret`

3 个 ECharts 图表：
- PE 走势（面积折线图）
- VIX 走势（颜色分段折线图）
- 历年收益与回撤（柱状图 + 折线图双轴）

所有图表通过 `loadCharts()` 函数并行加载 4 个 API 后渲染。

### 5.3 § II 主观评估（Tab 1）

基于马克斯《周期》中的市场评估清单：

```javascript
const CHECKLIST_DATA = [
  ['经济繁荣兴旺', '经济低迷疲软'],
  ['市场前景积极乐观', '市场前景消极悲观'],
  // ... 13 对对立描述
];
```

- 用户点击左侧（上行周期特征）或右侧（下行周期特征）
- 分数 = `左侧选择数 / 13 × 100`
- 结果实时更新温度仪表盘

### 5.4 § II 数据评估（Tab 2）— 核心算法

详细算法参见《周期温度算法说明.md》，此处描述实现流程：

**数据加载** (`loadDataAssessment`)：
1. 并行请求 11 个 API
2. 从每个响应中提取原始数值，存入 `rawValues` 对象
3. 调用 `renderDataTable(rawValues)`

**评分计算** (`renderDataTable`)：
1. 遍历 `SIGNAL_CONFIG`，对每个信号调用 `piecewiseScore(raw, breakpoints)` 得到 0-100 连续分
2. 按 `CATEGORIES` 分组，计算每个类别的加权平均子分数
3. 四个类别子分数按权重（30/25/25/20）聚合为综合温度

**渲染输出**：
1. 类别概览卡片（4 个进度条 + 分数）
2. 综合温度条（彩虹渐变 + 大字分数 + 标签）
3. 分组表格（每个信号：数值、迷你进度条、分数、权重、数据源）
4. 可展开的"算法说明"

### 5.5 § III 温度仪表盘

CSS 实现的彩虹渐变条 + 指针：

```css
.gauge-bar {
  background: linear-gradient(to right,
    #3b82f6 0%, #22c55e 25%, #eab308 50%, #f97316 75%, #ef4444 100%);
}
.gauge-needle {
  transition: left 0.8s cubic-bezier(0.34, 1.56, 0.64, 1);
}
```

指针位置通过 `style.left = score + '%'` 控制。

### 5.6 Tab 切换联动

切换 Tab 时自动更新仪表盘：
- 切到「数据评估」→ 显示数据驱动的 `dataScoreOverride`
- 切到「主观评估」→ 显示用户手动选择的分数

## 七、Step 6 — 主题切换功能

### 7.1 实现步骤

1. **CSS**：在 `style.css` 中添加 `[data-theme="light"]` 覆盖所有 CSS 变量
2. **JS**：在 `common.js` 的 `renderNav()` 中添加 `.theme-toggle` 按钮
3. **JS**：`initTheme()` 在脚本加载时立即执行，从 `localStorage` 恢复主题
4. **JS**：`toggleTheme()` 切换 `data-theme` 属性，更新 `localStorage` 和图表配色

### 7.2 注意事项

- `initTheme()` 必须在 `DOMContentLoaded` 之前执行，避免页面闪烁（FOUC）
- 图表配色通过 `CHART_THEME` 对象动态更新，但已渲染的图表不会自动重绘
- Header 背景色需要在 `[data-theme="light"]` 中单独覆盖（因为使用了 `rgba` 值而非变量）

## 八、关键问题与解决方案

### 8.1 API 数据格式变更

| 问题 | 原格式 | 新格式 | 解决 |
|------|--------|--------|------|
| 年度收益 | `data.years[].return` | `data.series[].value`（百分比形式） | 改用 `series` 数组，值直接是百分比 |
| 年内回撤 | `data.years[].maxdd` | `data.annual[].dd` | 改用 `annual` 数组，字段名改为 `dd` |
| VIX 数值 | `d.close` | `d.value` | 统一使用 `value` 字段 |

### 8.2 跨域请求

- historyofmarket.com 和 dollarliquidity.com 均配置了 CORS 头，允许跨域访问
- 所有 API 均为 GET 请求，无需认证

### 8.3 ECharts 图表响应式

```javascript
window.addEventListener('resize', () => chart.resize());
```

每个图表实例创建后都注册 resize 监听。图表容器使用 `width: 100%; height: 360px`。

### 8.4 缺失数据容错

- `fetchJSON()` 捕获所有错误并返回 `null`
- 渲染前使用可选链检查：`if (peData?.trailing?.length)`
- 权重聚合时自动重新归一化：`/ Σ(可用信号权重)`

## 十、部署

| 平台 | 方式 |
|------|------|
| GitHub Pages | 推送到 `gh-pages` 分支 |
