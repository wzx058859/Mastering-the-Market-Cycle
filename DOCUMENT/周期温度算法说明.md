# 周期温度算法说明

> 本文档详细描述「周期温度计」网页中数据驱动市场评估的算法设计、数学原理、参数选择依据和局限性。

---

## 一、算法概览

周期温度算法将 13 个实时市场指标转换为一个 0-100 的综合温度分数，用于评估当前市场在周期中的位置。

- **0 = 极冷**：市场处于恐惧/底部区域，历史上往往对应买入机会
- **50 = 温和**：周期中段，信号混合
- **100 = 极热**：市场处于贪婪/顶部区域，历史上往往需要提高警惕

算法分三个步骤：**分段线性映射** → **分层加权聚合** → **温度仪表盘输出**。

---

## 二、方法论来源

算法设计综合参考了以下成熟方案：

| 来源 | 关键借鉴 |
|------|----------|
| **CNN Fear & Greed Index** | 7 个指标等权组合为 0-100 连续分数的框架 |
| **DollarLiquidity DLI** | robust z-score 标准化 + 四级传导权重（政策 65%、资金 10%、信用 5%、风险 20%）+ CISS 二次型共振放大 |
| **Market Crash Monitor** | 分层结构：估值锚定 > 系统性压力 > 杠杆 > 情绪 |
| **BuildersLens** | 5 层 65 信号架构，考虑持续性和广度 |
| **芝加哥联储 NFCI** | 105 指标因子分析，等权组合"不逊于复杂统计方法" |
| **ECB CISS** | 二次型聚合放大共振信号 |
| **AIAE 回归模型** | `subsequent_10y_ann = 0.265 − 0.623 × AIAE`，R² ≈ 0.5 |

## 三、第一步：分段线性映射（Piecewise Linear Scoring）

### 3.1 原理

每个指标定义一组 `[原始值, 温度分]` 断点对。当原始值落在两个断点之间时，通过线性插值计算温度分。

```
piecewiseScore(value, breakpoints):
    如果 value ≤ 第一个断点的值 → 返回第一个断点的分数
    如果 value ≥ 最后一个断点的值 → 返回最后一个断点的分数
    否则找到 value 所在的区间 [v₀, v₁]，对应分数 [s₀, s₁]：
        score = s₀ + (value - v₀) / (v₁ - v₀) × (s₁ - s₀)
```

### 3.2 为什么用分段线性而非三态判断

旧算法将每个指标划分为「危险 / 中性 / 机会」三态，存在严重信息损失：

- PE = 26 和 PE = 40 都是"危险"，但风险程度完全不同
- 中性区间过宽，无法区分"刚进入中性"和"即将触发危险"
- 最终温度 = `危险数 / 总数 × 100`，等权且丢失程度

分段线性映射将每个指标转换为连续 0-100 分数，保留了：
- **程度信息**：PE = 26 → 72 分，PE = 40 → 100 分
- **非线性关系**：可以在关键阈值附近增加斜率（更敏感）
- **方向一致性**：统一为"越高越热/越危险"

## 四、第二步：分层加权聚合

### 4.1 类别划分与权重

13 个信号分为 4 个类别，每个类别有一个总权重：

| 类别 | 权重 | 包含信号 | 权重依据 |
|------|------|---------|---------|
| **估值信号** | **30%** | PE (15%), AIAE (15%) | AIAE 是已知最强的长期周期预测因子（R² ≈ 0.5）；CAPE/PE 是最广泛使用的估值指标 |
| **信用与利率** | **25%** | HY 利差 (8%), 收益率曲线 (8%), 10Y 利率 (5%), 实际利率 (4%) | 信用条件是中期领先指标；收益率曲线倒挂预测了 1970 年以来每次衰退 |
| **情绪与市场** | **25%** | VIX (10%), 年度收益 (8%), 回撤 (7%) | 直接可观测的周期行为特征；CNN F&G Index 核心指标 |
| **宏观流动性** | **20%** | DLI (6%), M2 (6%), DXY (4%), 2Y 利率 (4%) | 参考 DollarLiquidity 的四级传导框架；货币环境是周期的底层驱动力 |

### 4.2 权重分配依据

1. **估值权重最高**：学术研究一致表明长期估值指标（CAPE、AIAE、Buffett Indicator）是后续长期回报最强的预测因子。巴菲特称市场总值/GDP 比率是"在任何给定时刻衡量估值水平的最佳单一指标"。

2. **信用与情绪并重**：Market Crash Monitor 将估值锚定和系统性压力（信用+收益率曲线）作为最高层级指标；CNN F&G Index 以情绪和市场行为为核心。两者各占 25%。

3. **流动性作为背景**：DollarLiquidity 的方法论强调流动性是"缓慢的、同步的指标——衡量当前状态，不是预测工具"，因此权重最低。

4. **等权 vs 差异化权重**：芝加哥联储和 FTSE Russell 的研究表明等权组合"不逊于复杂统计方法"。但我们在类别间做适度差异化（30/25/25/20 而非 25/25/25/25），以体现估值指标在长期预测中的显著优势。

### 4.3 聚合计算

#### 类别子分数

对每个类别，计算其中所有已成功加载信号的加权平均：

```
类别子分数 = Σ(信号分数 × 信号权重) / Σ(信号权重)
```

权重在计算时会重新归一化，确保部分信号加载失败不影响结果。

#### 综合温度

```
综合温度 = Σ(类别子分数 × 类别权重) / Σ(类别权重)
```

同样对可用类别重新归一化。

#### 计算示例

以 2026 年 5 月实际数据为例：

| 信号 | 数值 | 温度分 | 权重 |
|------|------|--------|------|
| PE | 28.5 | 81 | 15% |
| AIAE | 48.2% | 88 | 15% |
| HY Spread | 284bp | 78 | 8% |
| Yield Curve | 0.47% | 46 | 8% |
| 10Y Rate | 4.47% | 32 | 5% |
| Real Yield | 1.89% | 22 | 4% |
| VIX | 18.4 | 58 | 10% |
| Annual Return | 8.2% | 46 | 8% |
| Drawdown | -9.1% | 59 | 7% |
| DLI | -0.09 | 35 | 6% |
| M2 YoY | 6.8% | 54 | 6% |
| DXY | 119.1 (z=~0) | 44 | 4% |
| 2Y Rate | 4.00% | 35 | 4% |

类别子分数：
- 估值：(81×15 + 88×15) / (15+15) = **85**
- 信用与利率：(78×8 + 46×8 + 32×5 + 22×4) / (8+8+5+4) = **50**
- 情绪与市场：(58×10 + 46×8 + 59×7) / (10+8+7) = **54**
- 宏观流动性：(35×6 + 54×6 + 44×4 + 35×4) / (6+6+4+4) = **43**

综合温度：(85×30 + 50×25 + 54×25 + 43×20) / (30+25+25+20) = **60**

## 七、局限性与改进方向

### 当前局限

1. **阈值主观性**：断点基于历史经验和专家判断，不是通过机器学习或回测优化的。不同利率环境下"合理"的 PE 水平不同（低利率时市场可以承受更高的 PE）。

2. **等权类别内聚合**：类别内使用按权重的简单加权平均，没有考虑 DollarLiquidity 那样的共振放大效应（当多个信号同时恶化时，风险应该超线性增长）。

3. **静态权重**：权重在不同市场环境下保持不变。理想状态下，权重应该根据当前周期阶段自适应调整。

4. **美国市场中心**：所有数据源都是美国市场指标，对全球投资者的适用性有限。

5. **滞后性**：AIAE 季度更新，M2 月度更新，部分信号有 1-7 天的发布滞后。

### 可能的改进方向

1. **CISS 二次型聚合**：参考 ECB 和 DollarLiquidity 的做法，使用 `√(s' · (W ⊗ Σ) · s)` 替代简单加权平均，其中 Σ 是信号间的滚动相关矩阵——当信号共振时放大评分。

2. **滚动百分位标准化**：将断点替换为基于 5-10 年滚动窗口的历史百分位，自动适应结构性变化。

3. **加入更多信号**：CAPE Shiller PE、Margin Debt、Put/Call Ratio、AAII 投资者情绪调查、ISM PMI 等。

4. **多市场扩展**：加入 A 股（沪深 300 PE、融资余额、北向资金）和港股指标。

5. **回测验证**：对历史数据运行算法，检验温度分数与后续 1/3/5 年回报的相关性。

## 八、核心代码

### piecewiseScore 函数

```javascript
function piecewiseScore(value, breakpoints) {
    if (value <= breakpoints[0][0]) return breakpoints[0][1];
    for (let i = 1; i < breakpoints.length; i++) {
        if (value <= breakpoints[i][0]) {
            const [v0, s0] = breakpoints[i - 1];
            const [v1, s1] = breakpoints[i];
            return s0 + (value - v0) / (v1 - v0) * (s1 - s0);
        }
    }
    return breakpoints[breakpoints.length - 1][1];
}
```

### 加权聚合

```javascript
// 类别子分数
const catScore = signals
    .filter(s => s.score != null)
    .reduce((sum, s) => sum + s.score * s.weight, 0)
    / signals.filter(s => s.score != null).reduce((sum, s) => sum + s.weight, 0);

// 综合温度
const overall = categories
    .filter(c => c.subScore != null)
    .reduce((sum, c) => sum + c.subScore * c.weight, 0)
    / categories.filter(c => c.subScore != null).reduce((sum, c) => sum + c.weight, 0);
```
